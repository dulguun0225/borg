# Open

A question belongs here when an [owner](what-humans-do.md) decides it and the design cannot answer it by applying a pattern it already holds. It is phrased as the question and what turns on it, and is deleted from here once folded into the file that owns its subject.

## What the security predicate list ships with

[_What a consumer declares_](how-the-factory-works/07-contracts/06-what-a-consumer-declares.md) says a second list of predicate kinds exists beside the consumer contract's: the security predicates, decided per toolchain against a build, which an owner may extend and never narrow. It names no kind. What turns on it: until a kind is named, the Merge to master gate's rejection over that list can never fire, and the class of defect the [exposure factor](how-the-factory-works/04-risk-score/01-factors-at-least.md) leaves blind is covered by nothing else. It is an owner's question because each kind is a check over the code the factory writes, and no pattern the document holds says which checks those are.
