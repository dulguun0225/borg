# What the factory does

A **fully autonomous software factory and operations**: it refines intent, produces the software, deploys it, monitors it, finds issues, and fixes bugs, on its own. It also runs itself: it decomposes [intent](../how-humans-do-it/02-intent-into-items/01-intake/README.md) into [items](../how-humans-do-it/01-one-pipeline.md), dispatches its own [agents](../how-humans-do-it/01-one-pipeline.md) onto them, [gates](../how-humans-do-it/03-gates/01-where-a-gate-is-and-what-decides-it.md) its own output against a [score](../how-humans-do-it/04-risk-score/README.md) it learns, revises [what those agents are told](../how-humans-do-it/10-fleet/03-what-an-agent-is-told/README.md) from what its own decisions record, and escalates what it cannot finish. It does not compose its own [fleet](../how-humans-do-it/10-fleet/README.md): what an agent is told is the factory's, what it runs on is a human's — the sharpest division in the document. The factory is a product — each customer runs an isolated, self-hosted install. There is no tenancy: no shared install, no multi-tenant model, nothing about one customer's data another's factory could reach. The absence is a decision, not a gap left to fill. What it buys is that the [one graph](01-tight-integration.md) of records — every record, every [end-user report](../how-humans-do-it/02-intent-into-items/01-intake/02-reports.md), every line an agent read — is one customer's, reachable by no other customer and by nobody hosting a shared install, the condition a regulated customer installs under at all. What it costs is that nothing learned in one install reaches another: the [per-author prior](../how-humans-do-it/04-risk-score/01-factors-at-least.md) an install narrows over months is that install's alone, and a [provider](../how-humans-do-it/10-fleet/01-what-an-agent-runs-on.md) retiring a model version destroys it in every install at once with nothing to amortize it across them. The one channel is the product itself: the [role prompts](../how-humans-do-it/10-fleet/03-what-an-agent-is-told/README.md), [evaluation sets, and starting priors](../how-humans-do-it/10-fleet/02-a-model-under-a-name.md) it ships carry what [the builder](05-what-the-customer-runs-it-under.md) measured on the builder's own work, never what a customer's factory learned.
