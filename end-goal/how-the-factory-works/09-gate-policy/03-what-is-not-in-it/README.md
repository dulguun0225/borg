# What is not in it

Three things are next to gate policy and are not it. **The score.** An owner authors what the number is compared against, never how it is computed — the formula is published so a human can disagree with it, and the [vector](../../04-risk-score/README.md) behind it is learned from outcomes. **The stages.** A gate is where policy applies; what is between the gates is the factory's own — including [what an agent is told](../../10-fleet/03-what-an-agent-is-told/README.md) there, which the factory writes, versions, and puts through a gate of its own, and which an owner reaches only by adding a safeguard at that gate (9). **The form a criterion takes.** The [six patterns](../../03-gates/07-what-particular-gates-decide/02-spec/03-the-six-patterns.md) are a closed set and the factory owns the form, which is what lets it end the interview — an owner confirms criteria (6) and does not author the shape one may have.
