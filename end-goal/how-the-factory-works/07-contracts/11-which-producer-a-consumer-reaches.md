# Which producer a consumer reaches

Which producer each predicate of a [consumer contract](06-what-a-consumer-declares.md) is over is derived with it, and that field is the edge every cross-service check reads. A [contract](01-two-versioned-things.md) is one service's one interface, so resolving a predicate to one means finding which service the call site reaches. A call site does not say: the address it calls arrives through the service's [configuration file](../05-environments/01-records-and-one-long-lived-branch.md), a base URL, a topic, or a discovery name, and the value comes from the file at deploy. So each such address is an entry of that file naming the service and the interface it reaches, authored beside the code that reads it and diffed like the rest of the file. The extractor pairs each call site with the entry it reads its address from, and the consumer contract names, per predicate, the producer contract the pairing resolves to. That field is the only place the edge between two services is held. The [service record](../02-intent-into-items/03-decomposition/README.md) carries no dependency set, because the set is derived from the build at every release and a copy on the service record would be the same fact twice, one of them stale. An entry may declare its address outside the factory, and a call through it is covered by nothing, which [_Two versioned things_](01-two-versioned-things.md) already says of such a call.

Three readers read the field, and none reads an absence as no edge. [Enforcement](04-enforcement.md) reads a producer's consumers as the consumer contracts in force naming its contract, and the [context factor](../04-risk-score/01-factors-at-least.md) reads the same query. The [deployer](../08-operations/01-the-health-monitor.md) composes a [candidate's environment](../05-environments/02-an-environment-per-candidate/README.md) from the producers the candidate build's consumer contract names, and theirs through their current releases' consumer contracts. It writes each entry's address for that environment at composition, which is what lets one file serve every environment. A call site whose address the extractor cannot trace to an entry, a literal in the code or a value read from the store, is [could not derive](06-what-a-consumer-declares.md) for that consumer contract, and so is an entry naming no service for an address inside the factory. So an edge the analysis did not find is told from an edge that does not exist, and a consumer with a could-not-derive contract is on every producer's [deprecation list](08-deprecation.md) and in no candidate environment's composition, the human at the gate being what decides it. What it costs is an entry an author writes per address, and an environment composed from an entry authored wrong, whose run decides against a producer the code never calls. A service whose file names no producer for an address it reaches is could not derive until its entries are authored, which is the state an [adopted](../02-intent-into-items/03-decomposition/01-a-service-that-already-exists.md) service arrives in.
