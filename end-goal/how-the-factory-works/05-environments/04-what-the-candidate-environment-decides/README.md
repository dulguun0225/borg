# What the candidate environment decides

[The graph](../../../what-the-factory-does/01-tight-integration.md) is not uniform. Up to the merge, what moves is a candidate and deploys are plain: no strategy, no rollout, and no [_analysis window_](../../08-operations/02-the-analysis-window.md), because a candidate environment has no organic traffic, and a comparison computed from one human exercising a screen is noise that looks like evidence. A [quality criterion](../../03-gates/07-what-particular-gates-decide/02-spec/03-the-six-patterns.md) is not that comparison: it is decided under load its own encoding generates, an absolute reading establishing nothing past this environment's hardware. What the environment decides is every criterion whose encoding declares it, as [_Implementation_](../../03-gates/07-what-particular-gates-decide/05-implementation/README.md) states. A criterion whose encoding declares the build was decided by [the build runner](../01-records-and-one-long-lived-branch.md) as it built; this environment decides the rest. The candidate runs on production-like infrastructure against its dependencies' current releases, every consumer contract is checked against it, and the predicate-kind [constraints](../../02-intent-into-items/01-intake/01-constraints-and-the-design-system.md) in force are decided against what the same run shows. The factory's own list of security predicates is decided against the same run, beside the criteria, with one set of derivations per toolchain; a toolchain whose derivation could not run reads as [could not derive](../../07-contracts/06-what-a-consumer-declares.md). A [store's](../../07-contracts/09-the-store-is-a-contract-too.md) is checked the same way, against a state rather than an exchange: the store the run leaves behind, seeded as [_An environment per candidate_](../02-an-environment-per-candidate/README.md) states, carrying the item's own schema change. So the reads and writes of every release a rollback could restore are decided before production. A criterion that fails is a rejection at the Merge to master gate on the same terms a consumer contract failing there is, [unreliable](../../03-gates/07-what-particular-gates-decide/02-spec/02-in-force-and-withdrawal.md) criteria excepted. What it costs is that the encoding's author declares the split.
