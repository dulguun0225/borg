# Spec

One duty, and one confirmation already made. [_The interview_](../../../02-intent-into-items/02-the-interview.md) (3) refines intent and the spec is what it produces. The person who asked confirmed the factory's reading of the request at the interview's last round, which no score gates, so there is no interview gate and none is missing. A spec version names the acceptance criteria it introduces and the ones it withdraws, so approving it confirms that change to the set (6). What is confirmed is the criteria: the encoding that decides them against an observed run is authored at [_Implementation_](../05-implementation/README.md) and is downstream of this approval, not the object of it.
