# The record

A criterion is a record of the service and the spec does not restate it. A restated criterion would let the spec and the criterion disagree, which is the reason an item names no [project](../../../11-screens/01-work-ops-factory-people.md), and it would make ids stable and never reused a rule about nothing. The record is written exactly once, by the [artifact store](../../../01-one-pipeline.md) in the same call that submits the spec version introducing it, and never written again. Withdrawal is recorded on the withdrawing spec version, so a version the gate rejects takes its withdrawal down with it.

A criterion's provenance has two sources and a default, read at introduction. **Constraint-derived** is a field the artifact store writes once, in the same call, naming each [constraint](../../../02-intent-into-items/01-intake/01-constraints-and-the-design-system.md) record the drafting stage held as its evidence for the criterion. It is a link and not a mark, so that two questions are queries over the field: which criteria in force stand for a constraint, and which criteria in force were drafted under a constraint since withdrawn or replaced. [Factory](../../../11-screens/01-work-ops-factory-people.md) lists both, the second beside each withdrawn constraint whose criteria still stand, so a rule no longer in force and still enforced is visible rather than silent; withdrawing such a criterion is an item like any other, and the constraint's own withdrawal removes none of them. **Human-confirmed** is not a field but a query over the introducing spec version's [decision](../../01-where-a-gate-is-and-what-decides-it.md), which carries the actor and the resolved vector, the way in force is already a query. Everything else is factory-drafted. What that costs: a criterion whose introducing decision the [log](../../../../deferred.md)'s retention cut removed reads as unknown provenance, and unknown resolves toward the gate; and a criterion is constraint-derived only where the drafting stage named the constraint as its evidence, so one drafted under a constraint the stage read and did not cite is factory-drafted, and the listing above misses it.
