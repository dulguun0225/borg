# The attempt limit

Every stage has an attempt limit, authored with the rest of [gate policy](../09-gate-policy/README.md) (8). An item that exceeds it stops being retried and appears in [_Work_](../11-screens/01-work-ops-factory-people.md) as an escalation (12) — the factory saying it cannot do this one. What the limit is compared against is the item's own count for the stage it is at, which [_What an item names_](../02-intent-into-items/03-decomposition/02-what-an-item-names.md) keeps per stage and [dispatch](../02-intent-into-items/05-dispatch.md) writes: counting the rejects in the log instead would miss every attempt that failed before a gate fired, which is exactly what a high limit spends [agent](../01-one-pipeline.md) time on. A deploy is not an attempt: the [deployer](../08-operations/01-the-health-monitor.md) performs it, no entry is dispatched to it, and dispatch writes no count for it. It is one parameter and not three: [_The interview_](../02-intent-into-items/02-the-interview.md) counts its rounds against the same limit, and decomposition counts its re-decompositions against it, both on the intent and both upstream of an item's first stage, the interview having no gate of its own and decomposition's gate deciding a set rather than an item. A second row would be a different number on the same mechanism, a row whoever builds the factory implements twice.

 Holds do not count against the limit; a hold is not a failed attempt, for the same reason the score does not learn from one. The limit is wrong in both directions: low turns solvable work into human work and stops an interview about to converge; high spends agent time before anyone sees the item. That spending is bounded by the [_spend ceiling_](../10-fleet/08-a-spend-ceiling.md) where an owner authored one on the credential the agent runs on (a limit on units spent through it, reaching which is a hold), and by the quota on the [provider account](../10-fleet/01-what-an-agent-runs-on.md) behind it otherwise. The two limits are one construction: this one counts attempts and the ceiling counts units, and each compares against the factory's own record rather than against anything at the provider.
