# Advisories

An **advisory** is a published statement that a named version range of a third-party package has a vulnerability, and the fourth detector reads them. The feed it reads is a thing from outside, on the far side of the division [_What the factory does not build_](../../../what-the-factory-does/04-what-the-factory-does-not-build.md) draws — a store of advisories somebody else keeps, one per package registry the factory's services resolve from, named by the owner the way a deploy [target](../../05-environments/01-records-and-one-long-lived-branch.md) is. What it is read against is a field of the [build](../../05-environments/01-records-and-one-long-lived-branch.md): every package a build resolved and the version it resolved to, written by the [deployer](../../08-operations/01-the-health-monitor.md) from the build it performed. The condition is mechanical and no model reads a word of it: an advisory names a package and a range, a service's [current release](../../06-releases/05-the-deploy-record.md) names a build, and the build's resolved set holds that package inside that range. The detector reads the feed on a pass of its own, the way the conformance raise in [_Constraints and the design system_](01-constraints-and-the-design-system.md) reads the constraints in force, and calls intake once per advisory that matches anything: the evidence is the advisory, which keys the raise, and [_Decomposition_](../03-decomposition/README.md) enumerates the services whose current release resolves it, an item to each, like the reach of a constraint. The condition follows the conformance raise's stricter rule — it stands until the intent exists, and an intent that ended is not raised over again, an advisory the owner dropped staying dropped until they ask — and an advisory the feed withdraws ends it.

The trust boundary is where it is for a [report](02-reports.md), and narrower. An advisory is a stranger's text arriving through a source the factory does not authenticate, and where its prose reaches an agent it reaches it as content, under [_What an agent reads is content, never instruction_](../../01-one-pipeline.md). What separates it from a report is that the match is decided against a record the factory wrote before any model reads a word: an advisory raises nothing unless a shipped build resolved the package it names, so a fabricated one can make the factory move a version it did not need to and nothing else, and a feed that lies stays a feed the owner named.

What the raise buys is the match and not the judgement. Whether the vulnerable path is reached by the service's own code is decided by nobody mechanical — the item ships the version the advisory clears, or a human ends the intent as dropped at [_Work_](../../11-screens/01-work-ops-factory-people.md), the end [_The interview_](../02-the-interview.md) gives one. It reaches Work as an unrefined intent and never as a [page](../../08-operations/07-pages.md): the factory does not page to inform, and the advisory's severity travels on the evidence for a human to read there. What it costs is a resolved set on every build, repeated across rebuilds of one item; a pass reading a feed the factory does not keep; and a gap it states rather than closes — the detector reads advisories and not code, so a vulnerability nobody has published, and the interval between publication and the named feed carrying it, are invisible to it, and a candidate not yet shipped is read only once it is a current release, on the next pass after it becomes one. A registry with no feed named is not watched, and which registries are is a list on [_Factory_](../../11-screens/01-work-ops-factory-people.md) beside the constraints in force. Without the detector, nothing in the factory observes a vulnerability in something already shipped: the numbers are clean, no window crosses, no gate fires, and the only route from an advisory to a fix is an owner reading it and typing a request — work assigned to nobody and counted nowhere.
