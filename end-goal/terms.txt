# The names this document uses, and the field each comes from.
#
# Every run of **bold** in end-goal/ that is not a paragraph lead-in, lowercased
# and sorted, then a tab and the field that owns the word in the sense used here —
# or `coined` where no field does, and `ordinary` where the run is a plain word or
# emphasis rather than a name. The consistency pass in CLAUDE.md fails on a bolded
# name that is not here; it reads the name alone and ignores what follows the tab.
#
# A line is not a decision, an endorsement, or a definition. It says the name
# exists and where the word comes from, the way factory/deps.txt says an edge
# exists, and nothing more. A field is a checkable fact about the outside world
# rather than a judgment about this design, which is what keeps this file out of
# the authority problem the root CLAUDE.md describes; the reasoning for a
# contested one goes in the commit body and never in this file.
#
# Adding a line means the commit that adds it says which of the two grounds in
# the root CLAUDE.md the name survives on. Additions fail the check; removals do
# not — the vocabulary cleanup that ran to 2026-08-23 removed names constantly,
# and a check that fought that would have blocked the work it exists to protect.
# So the one thing this stops is the pile growing back.
#
# A few of these are emphasis rather than names — git, always true, the change —
# and are here because the extraction cannot tell the difference, not because
# they are terms.
#
