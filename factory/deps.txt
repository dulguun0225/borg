# The allowed package graph. cmd/depscheck reads this file and fails the
# build on an import between two packages of this module that the file does
# not allow, so a wrongly wired package is caught by the build and not by a
# reviewer. The compiler already refuses a cycle; this refuses an edge that
# compiles and should not exist.
#
# A line is a package path relative to factory/, optionally followed by "->"
# and the packages it may import. A package with no arrow may import nothing
# inside this module. Only imports of this module are checked: the standard
# library and pgx are ignored, and a package that is not listed is an error,
# so adding one means adding a line here.
#
# A line beginning with "test" allows an edge that appears only in a package's
# test imports. Every record package's database tests are in an external test
# package and open the pool through postgres, which that package cannot import
# itself once postgres applies its DDL — the arrangement decisionlog's line
# has carried since M0 — so each record package has a test line naming
# postgres. decisionlog's also names secretref for the demonstration that a
# resolved secret's value reaches no record, which is the one test that needs
# a secret and a database at once. score's names gate and policy: the outcomes
# it counts are the decisions a gate wrote, so its tests fire real gates rather
# than writing those rows by hand, and a gate is fired with a policy.
#
# Five edges deserve their reason stated.
#
# artifact -> criterion is the one import between two record packages that
# both own tables: the artifact store is the criterion's one writer, so the
# spec version and the criteria it introduces are written in one transaction.
#
# gatepolicy is imported by everything that holds an authored value and by
# nothing it imports itself. It owns no table and is the vocabulary of gate
# policy — the parameters, what each value means, and the direction a pin on it
# points — which two packages would otherwise each keep a copy of.
#
# score reads the graph, so it imports the record packages the factors are
# computed from: the artifacts an author wrote, the closed decisions in the
# log, the items in an area, and the releases of a service. It writes only its
# own version record. What it does not import is a repository: the one input
# that is not a record is the build's diff, measured by the component that
# built and handed to it.
#
# policy is Factory's writer, so it imports every record an owner authors a
# value on — the environment, the service, the area, the factory policy record,
# and the pin — and calls the transaction-taking write each of them exposes,
# appending the policy version inside the same transaction. It imports score
# for the value the score supplies where an owner authored nothing.
#
# cmd/factory imports nearly everything, because it is the crude interface the
# four surfaces are deferred with — the one place the whole path is composed,
# and the one place an owner can author a parameter or place a pin.
