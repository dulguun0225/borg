# The allowed package graph. cmd/depscheck reads this file and fails the
# build on an import between two packages of this module that the file does
# not allow, so a wrongly wired package is caught by the build and not by a
# reviewer. The compiler already refuses a cycle; this refuses an edge that
# compiles and should not exist.
#
# A line is a package path relative to factory/, optionally followed by "->"
# and the packages it may import. A package with no arrow may import nothing
# inside this module. Only imports of this module are checked: the standard
# library and pgx are ignored, and a package that is not listed is an error,
# so adding one means adding a line here.
#
# A line beginning with "test" allows an edge that appears only in a package's
# test imports. There is one such line, and postgres is on it because that is
# how a database test reaches the pool: postgres imports decisionlog to apply
# its DDL, so decisionlog cannot import postgres, but decisionlog's tests are
# in the external test package decisionlog_test, which the compiler treats as
# a separate package and lets import postgres. secretref is on it for the
# demonstration that a resolved secret's value reaches no record, which is the
# one test that needs a secret and a database at once.

record
decisionlog -> record
secretref
targetseam -> secretref
postgres -> decisionlog
cmd/depscheck

test decisionlog -> postgres secretref
